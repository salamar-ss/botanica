# Botanica — Natural Beauty & Skincare Store

Botanica is a modern e-commerce portfolio project for a natural beauty and skincare store. It features a clean, botanical-inspired design with a focus on usability, reusable components, and a smooth shopping experience.

## Live Demo

- **Live Website:** https://botanica-store.vercel.app/
- **GitHub Repository:** https://github.com/salamar-ss/botanica

## Features

- Product catalogue powered by the DummyJSON API
- Product search, filtering, and sorting
- Product details pages
- Shopping cart with quantity management
- Wishlist functionality
- Persistent cart and wishlist state
- Checkout form with validation
- Mock order confirmation
- Loading, error, empty, and retry states
- Application-level error boundary
- Responsive layout
- Reusable UI components

## Tech Stack

- React

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd react-store
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## API

Product data is provided by [DummyJSON](https://dummyjson.com/).

Checkout is simulated for demonstration purposes. No real payments are processed and no actual orders are placed.

## Project Goals

This project demonstrates practical React and TypeScript development, including component composition, client-side routing, API integration, server-state management, persistent client state, form validation, and error handling.
